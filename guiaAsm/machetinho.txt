; x2 --> RSI ESI SI  SIL
; x3 --> RDX EDX DX  DL
; X4 --> RCX ECX CX  CL
; X5 --> R8  R8D R8W R8B
; X6 --> R9  R9D R9W R9B
; x7 --> [rbp + 16] Despues de pushear rbp

; PARAMETROS FLOTANTES: foo(x1,..,x8);
; x1 --> XMM0

; x3 --> XMM2
; X4 --> XMM3
; X5 --> XMM4
; X6 --> XMM5
; X7 --> XMM6
; X8 --> XMM7

RESULTADO: En entero o puntero: RAX, EAX, AX, AH, AL
           En flotante: XMMO0

NO VOLATILES 32: EBX, EBP, R12D,  R13D, R14D, R15D.
NO VOLATILES 16: BX , BP , R12W,  R13W, R14W, R15W.
NO VOLATILES 8L: BL , BPL, R12B,  R13B, R14B, R15W.

x/s DIRECCION → interpreta la dirección como string.
x/4s DIRECCION → muestra 4 strings seguidos en memoria.
x/16bx DIRECCION → muestra 16 bytes en hexadecimal desde la dirección.
x/16cb DIRECCION → muestra 16 bytes como caracteres (útil si querés ver ASCII aunque no haya \0).

x/NFU DIRECCION

N = cuántas unidades mostrar.
F = formato (x = hex, d = decimal, u = unsigned, c = char, 
    s = string, i = instrucción).
U = tamaño de la unidad (b = byte, h = halfword 2 bytes, 
    w = word 4 bytes, g = giant word 8 bytes).

>>> x/s $rbx
0x7fffffffd150: "A1"
